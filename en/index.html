What a Noon cashback code does

A Noon cashback code returns part of what you spend instead of cutting the price at checkout. With this offer the return is 10% of the eligible amount, never more than AED 75 in the UAE or SAR 75 in Saudi Arabia. Which part of your basket counts as eligible is Noon's decision.

How big can the cashback get?

  • Eligible spend of 400 gives 10% = 40, below the cap.
  • Eligible spend of 1,000 gives 10% = 100, cut to the 75 cap.
  • Once eligible spend passes 750, you are at the cap and extra spend adds nothing.

These are arithmetic examples, not a promise that your order qualifies. Read the cashback guide (Arabic) for the longer explanation.

Noon promo code UAE or KSA: use the right store

Each Noon country store has its own currency and conditions. Head to the Noon promo code UAE page for dirham amounts or the Noon promo code KSA page for riyal amounts, and use a code only in the store it is listed for.

Reading a code's status

Many coupon sites call every code "working". We do not. A card shows its verification status, plus expiry and minimum order only where we were given them. Our rules are on the verification page (Arabic).

Apply a Noon code in five steps

  1. Add eligible items

    Pick products from your own country store. Some items and sellers can be excluded from a campaign.

  2. Go to cart, then checkout

    Keep going until you see the promo or coupon field. Its position can differ between the website and the app.

  3. Paste the code

    Copy a code from this page and paste it into the field. All codes are capital letters.

  4. Apply and check

    Look for an acceptance message or a discount or cashback line in the order summary. If nothing shows, do not assume the offer is on.

  5. Pay and keep proof

    Screenshot the order summary before paying, then check the order details and your account afterwards.

Noon promo code FAQ

What is the current Noon promo code?

This page lists five: DMNX, OFQHU, WOWRJ, KILO and GOKU, all supplied by the site owner for a 10% cashback offer. We do not call any of them active today unless a test date is shown on its card. See how we check codes.

How can I get 10% cashback on Noon?

Add eligible items, enter one of the codes at checkout and confirm the offer shows in your order summary before you confirm. Noon's own cashback terms then decide when and how it is credited. More in the cashback guide.

What is the maximum cashback?

The announced offer is 10% capped at AED 75 in the UAE or SAR 75 in Saudi Arabia. Anything above the cap is cut off at 75.

Are UAE and Saudi promo codes the same?

The five codes are listed for both markets, but each Noon store has its own currency and conditions, so a code may work in one and not the other. Use it in the store of the country you ship to. See the UAE page and the Saudi page.

How do I apply a Noon discount code?

Paste the code into the coupon field at checkout and press apply. The full walkthrough is in the how-to guide (Arabic).

Why is my coupon code not accepted?

Common causes: a typo, an excluded product in the cart, the wrong country store, an account or order condition you do not meet, or an offer that has ended or hit its limit. Retype the code, remove excluded items, check the country and currency, then try another code.

How can I verify that the cashback was applied?

Before paying, look for the code or cashback line in the order summary. After paying, check the order details and your account, and keep screenshots. If it is missing after the period Noon's terms state, contact Noon support with the order number.
